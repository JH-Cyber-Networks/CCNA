## Overview
This laboratory project focuses on physically interconnecting network devices using appropriate cable types (Copper Straight-Through, Crossover, Fiber, Serial DCE/DTE) and properly configuring interfaces across routers, switches, and end hosts.

## Network Topology
`net-topology/topology.png`

## Devices Included
* **Routers**: R1, R3 (equipped with serial/fiber modules)
* **Switches**: LAN access switches
* **End Devices**: PCs, Servers
* **Cloud**: Internet / WAN Simulation Cloud

## Skills Demonstrated
* Network topology layout and device placement in Packet Tracer
* Selection and connection of physical Ethernet, Serial, and Fiber interfaces
* Verification of physical layer link statuses and connection types

## How to View
1. Clone or download this repository.
2. Open `Lab2 - Connecting Devices.pkt` using **Cisco Packet Tracer**.
