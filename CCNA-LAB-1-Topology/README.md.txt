# CCNA Lab 1: Multi-Branch Network Topology

## Overview
This laboratory project demonstrates the creation and configuration of a multi-branch network topology using Cisco Packet Tracer.

## Network Topology
![Network Topology](topology.png)

## Devices Included
* **Routers:** 2x Cisco 2911
* **Switches:** 2x Cisco 2960-24TT
* **Firewalls:** 2x Cisco ASA 5505
* **End Devices:** PCs, Servers, and Internet Simulation Cloud

## Key Concepts & Skills Demonstrated
* Network topology layout and device placement in Packet Tracer
* Physical and logical device connection cabling
* Basic routing and firewall node placement for enterprise branch office setup

## How to View
1. Clone or download this repository.
2. Open `CCNA-Lab-1-Topology.pkt` using **Cisco Packet Tracer**.
